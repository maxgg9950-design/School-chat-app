# School Chat – Android app

Native Android app that opens your School Chat website full-screen.

**Default site:** https://text-world.nekoweb.org/chat.html

## Fastest way to get an APK

**You don’t need Android Studio.** Follow:

### → [HOW_TO_GET_APK.md](HOW_TO_GET_APK.md)

That uses free GitHub Actions to build `app-debug.apk` for you in a few minutes.

## What’s included

- Full-screen WebView of School Chat  
- Image / GIF picker  
- Mic + camera for calls and voice messages  
- Pull-to-refresh, offline screen  
- Opens text-world.nekoweb.org links in the app  

## Advanced: build on your PC

Install [Android Studio](https://developer.android.com/studio) → Open this folder → Run ▶  
or `./gradlew assembleDebug`

Version **4.4.0** (`versionCode` 440).
